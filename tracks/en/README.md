# Organization-specific tracks

The [universal process](../../docs/universal-process.md) remains the backbone. These tracks adapt the effort, roles, and evidence without removing essential gates.

| Track | Starting point |
|---|---|
| [Independent professional](independent.md) | 14 days, one workflow |
| [Micro-business / TPE](tpe.md) | 30 days, one shared process |
| [SME / PME](pme.md) | 90 days, portfolio and platform |
| [Nonprofit or foundation](nonprofit-foundation.md) | 60 days, mission and beneficiaries |
| [Public service](public-sector.md) | Formal gates, mandate, and recourse |
