## Deterministic checks

- [ ] Keyboard-only path and visible, unobscured focus
- [ ] Programmatic name, role, value, state, and status messages
- [ ] Text alternatives, captions, transcripts, and non-color cues
- [ ] Zoom, reflow, contrast, target size, and motion controls
- [ ] Accessible authentication without a cognitive-function test
- [ ] Errors identified, explained, and recoverable
- [ ] Documents and exported evidence are accessible
- [ ] No essential task depends only on drag, speech, vision, or hearing

## AI-specific checks

- [ ] The system does not infer disability or capability without valid authority
- [ ] Generated content preserves structure, language, and accessibility metadata
- [ ] Timeouts and streaming output do not prevent review
- [ ] Uncertainty, refusal, and escalation are understandable
- [ ] Assistive-technology users can inspect and correct the input and output
- [ ] A human and non-AI channel provides an equivalent essential outcome
- [ ] Accessibility failures appear in monitoring and incident procedures
